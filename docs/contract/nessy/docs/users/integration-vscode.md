# Visual Studio Code

> The VS Code extension (Beta) lets you see Nessy's changes in real-time through a native graphical interface integrated directly into your IDE, making it easier to access and interact with Nessy CLI.

### Features

- **Native IDE experience**: Dedicated Nessy CLI sidebar panel accessed via the Nessy icon
- **Auto-accept edits mode**: Automatically apply Nessy's changes as they're made
- **File management**: @-mention files or attach files and images using the system file picker
- **Conversation history**: Access to past conversations
- **Multiple sessions**: Run multiple Nessy CLI sessions simultaneously

### Requirements

- VS Code 1.85.0 or higher

### Installation

1. Download the latest extension release:
   👉 [**Download the latest release**](https://s3-msk.tinkoff.ru/nestor-companion/vscode/nessy-cli-vscode-ide-companion-latest.vsix)

2. In VS Code:
   **View → Extensions → ⚙️ (Install from VSIX)**

## Troubleshooting

### Extension not installing

- Ensure you have VS Code 1.85.0 or higher
- Check that VS Code has permission to install extensions
- Try installing directly from the Marketplace website

### Nessy CLI not responding

- Check your internet connection
- Start a new conversation to see if the issue persists
