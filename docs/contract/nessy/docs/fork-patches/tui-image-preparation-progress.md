# tui-image-preparation-progress

## AIDT

- AIDT-7162
- AIDT-8157

## Зачем

Чтение `@`-вложения и преобразование изображения через vision bridge выполнялись
до перехода TUI в состояние `Responding`. Интерфейс выглядел зависшим, повторные
команды молча отклонялись, а Escape не мог отменить подготовку запроса. Ошибка
чтения также могла оставить submission guard активным.

Патч включает состояние ответа только на время чтения `@`-вложений и
vision-конвертации, разрешает отмену подготовки, а также гарантированно возвращает
TUI в `Idle` после ошибки или отмены. Чистые slash-команды не включают индикацию ответа.

## Файлы

- `packages/cli/src/ui/hooks/useGeminiStream.ts` — состояние ответа, обработка
  ошибок подготовки и финальный сброс submission guard
- `packages/cli/src/ui/hooks/useGeminiStream.test.tsx` — регрессии для индикации,
  отмены и восстановления после ошибки

Кодовые точки помечены
