## Зачем

После взаимодействия с Desktop PET macOS могла считать его последним активным
окном приложения. Обработчик клика по Dock создавал основное окно только при
полном отсутствии `BrowserWindow`, поэтому существующий PET мешал восстановить
или поднять основное workspace-окно поверх других приложений.

Патч запоминает последнее активное управляемое workspace-окно отдельно от PET.
По клику на Dock оно восстанавливается и получает фокус. Если основных окон не
осталось, создаётся окно последнего сохранённого или первого доступного
workspace, даже когда PET продолжает работать.

## Файлы

- `packages/desktop/apps/electron/src/main/window-manager.ts` — отслеживает и возвращает последнее активное основное окно, исключая PET
- `packages/desktop/apps/electron/src/main/index.ts` — восстанавливает и фокусирует основное окно в обработчике macOS `activate`

Ключевые кодовые точки помечены
`// [nessy-fork] desktop-pet-dock-activation`.

## Откат

1. Вернуть проверку отсутствия всех `BrowserWindow` в обработчик `activate`.
2. Удалить отслеживание последнего активного управляемого окна.
3. Удалить маркеры `[nessy-fork] desktop-pet-dock-activation`, строку из реестра и этот файл.
