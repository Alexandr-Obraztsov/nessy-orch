# dp-byok-model-picker

## AIDT

AIDT-8041

## Зачем

Показывать личные модели из каталога бэка в стандартном `/model`.
`id` используется в запросах, `display_name` — в списке; `access_source: byok`
добавляет суффикс `(byok)`. Старый контракт с одним `name` сохраняется.

Каталог загружается при старте и авторизации через `/auth`; `/model` использует
уже загруженный список без запроса к бэку. При выборе применяются протокол,
контекст и параметры новой модели; отсутствующие в ней
параметры предыдущей DP-модели сбрасываются. Пользовательские настройки сохраняют
существующие правила приоритета.

## Файлы

- `packages/core/src/dp/dp-models-client.ts` — контракт каталога.
- `packages/core/src/models/modelsConfig.ts` — сброс параметров предыдущей модели.
- `packages/core/src/dp/dp-models-client.test.ts` — контракт и ошибки загрузки.
- `packages/core/src/models/modelsConfig.dpauth.test.ts` — параметры при переключении.
- `packages/cli/src/ui/commands/modelCommand.test.ts` — отсутствие запроса при `/model`.
- `packages/cli/src/ui/components/ModelDialog.test.tsx` — отображаемое имя и технический ID.
