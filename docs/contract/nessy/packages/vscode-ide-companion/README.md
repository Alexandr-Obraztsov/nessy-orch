# Nessy CLI Companion

Nessy CLI Companion — внутреннее расширение для интеграции Nessy CLI с Visual Studio Code и совместимыми IDE на базе VS Code.

## Возможности

- **Чат в IDE**: работа с Nessy CLI в отдельной боковой панели
- **Просмотр изменений**: проверка, редактирование и принятие изменений в стандартном diff-редакторе VS Code
- **Автоматическое применение изменений**: применение правок Nessy CLI по мере их создания
- **Работа с файлами**: упоминание файлов через `@`, прикрепление файлов и изображений
- **История и несколько сессий**: доступ к предыдущим диалогам и параллельная работа с несколькими сессиями
- **Контекст редактора**: передача открытого файла, позиции курсора и выделенного фрагмента

## Требования

- Visual Studio Code 1.85.0 или новее
- Доступ к внутренним ресурсам компании

## Установка

1. Скачайте [последнюю версию расширения](https://s3-msk.tinkoff.ru/nestor-companion/vscode/nessy-cli-vscode-ide-companion-latest.vsix).
2. Откройте в VS Code раздел **Extensions**.
3. Выберите **Install from VSIX...** в меню раздела.
4. Укажите скачанный `.vsix` файл.

После установки расширение проверяет наличие обновлений во внутреннем хранилище Nessy CLI.

## Начало работы

Откройте панель Nessy CLI одним из способов:

- нажмите значок Nessy CLI на панели VS Code;
- выполните команду `Nessy CLI: Open` через Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`).

## Команды

| Команда                          | Назначение                                  |
| -------------------------------- | ------------------------------------------- |
| `Nessy CLI: Open`                | Открыть панель чата Nessy CLI               |
| `Nessy CLI: Run`                 | Запустить Nessy CLI во встроенном терминале |
| `Nessy CLI: Accept Current Diff` | Принять отображаемые изменения              |
| `Nessy CLI: Close Diff Editor`   | Закрыть редактор и отклонить изменения      |
