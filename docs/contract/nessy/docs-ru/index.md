# Документация Nessy CLI

Добро пожаловать в документацию Nessy CLI. Nessy CLI — это агентный инструмент для написания кода, который работает в вашем терминале и помогает превращать идеи в код быстрее, чем когда-либо прежде.

## Разделы документации

### [Руководство пользователя](./users/overview)

Научитесь использовать Nessy CLI как конечный пользователь. Этот раздел охватывает:

- Базовая установка и настройка
- Распространённые сценарии использования
- Функции и возможности
- Опции конфигурации
- Устранение неполадок

### [Руководство разработчика](./developers/architecture)

Научитесь вносить вклад и разрабатывать Nessy CLI. Этот раздел охватывает:

- Обзор архитектуры
- Руководство по внесению вклада
- Основные концепции и детали реализации
- Инструменты и рабочий процесс разработки
- Разработка расширений и плагинов
