# Координация статистики использования токенов (Issue #4479)

## Контекст

Issue #4479 запрашивает видимость ежедневного потребления токенов Nessy CLI. В обсуждении issue
был уточнён объём работ: предпочтение отдаётся CLI-команде, поддержке экспорта,
ежемесячным сводкам и потреблению токенов в разрезе моделей. Комментарий мейнтейнера
также указал на необходимость координации со смежной работой над статистикой:

- #4252: метрики времени генерации в `/stats`, такие как TTFT, длительность генерации
  и TPS.
- #4182: счётчики масштаба сессии без контента для диагностики памяти.

## Решения по координации

1. **Использовать `/stats`, а не новую команду верхнего уровня.**
   Статистика использования токенов предоставляется через `/stats daily`, `/stats monthly` и
   `/stats export`, чтобы разделять существующую поверхность команды статистики с
   статистикой сессий и будущими метриками генерации.

2. **Сохранять счётчики токенов как локальный JSONL.**
   Каждый ответ API добавляет одну запись без контента в
   `usage/token-usage-YYYY-MM.jsonl` в директории времени выполнения. Это удовлетворяет
   требованиям ежедневной/ежемесячной агрегации без добавления SQLite в качестве новой зависимости.

3. **Разделить семантику времени из #4252.**
   Сводки использования токенов могут включать `apiDurationMs` — существующую
   длительность ответа API от конца до конца из телеметрии. Это намеренно названо
   длительностью API и не должно представляться как длительность генерации, TTFT или TPS.
   #4252 остаётся владельцем метрик времени генерации.

4. **Сохранить границы приватности и диагностики памяти из #4182.**
   Записи использования хранят только агрегированные счётчики и стабильные измерения:
   локальная дата, месяц, id сессии, модель, тип аутентификации, источник, счётчики токенов
   и длительность API. Они не хранят текст промпта, текст ответа, содержимое инструментов,
   пути к проекту, id промптов или id ответов.

5. **Экспорт остаётся только агрегированным.**
   Экспорты CSV и JSON — это сводки, а не сырые экспорты транскриптов. Они группируют по
   общему количеству, модели, типу аутентификации, комбинации модель/тип аутентификации
   и источнику.

## Не входит в объём

- Не реализовывать инструментацию TTFT/TPS/длительности генерации из #4252 здесь.
- Не расширять `/doctor memory` и не реализовывать #4182 в этом изменении.
- Не добавлять отдельную слэш-команду верхнего уровня для статистики токенов.
