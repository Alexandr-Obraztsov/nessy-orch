# Обзор Nessy CLI

[![@nestor/nessy-cli downloads](https://img.shields.io/npm/dw/@nestor/nessy-cli.svg)](https://artifactory.tcsbank.ru/artifactory/api/npm/npm-all/@nestor/nessy-cli/latest)

:::tip
Узнайте о Nessy CLI, инструменте для разработки и аналитики с агентным ИИ, который работает в вашем терминале и помогает превращать идеи в код ил документацию быстрее, чем когда-либо.
:::

## Начало работы за 30 секунд

### Установка Nessy CLI:

Рекомендуемый установщик использует автономный архив, когда он доступен для вашей платформы. Если он переключается на npm, должен быть доступен Node.js 20 или новее с npm в PATH.

**macOS — Self Service**

1. Откройте на вашем компьютере приложение **Self Service**. Оно уже
   установлено.
2. Введите в поиске `Nessy CLI`.
3. Нажмите **Install** под названием **Nessy CLI**.

**macOS — установка из терминала**

```bash
/usr/bin/curl -fsSL https://s3-msk.tinkoff.ru/nestor-companion/installation/v2/install-nessy.sh | bash
```

**Linux**

```bash
CURL=/usr/bin/curl
[ -x "$CURL" ] || CURL=/bin/curl
"$CURL" -fsSL https://s3-msk.tinkoff.ru/nestor-companion/installation/v2/install-nessy.sh | bash
```

Абсолютные пути используют системное хранилище сертификатов вместо `curl` из
Anaconda или другого окружения в `PATH`. В Linux проверяются оба стандартных
пути: `/usr/bin/curl` и `/bin/curl`.

**Windows PowerShell**

```powershell
irm https://s3-msk.tinkoff.ru/nestor-companion/installation/v2/install-nessy.ps1 | iex
```

PowerShell использует системное хранилище сертификатов и не вызывает `curl`
из `PATH`.

**Windows cmd.exe**

```cmd
"%SystemRoot%\System32\curl.exe" -fsSL -o "%TEMP%\install-nessy.bat" https://s3-msk.tinkoff.ru/nestor-companion/installation/v2/install-nessy.bat && "%TEMP%\install-nessy.bat"
```

Абсолютный путь обходит `curl.exe` из Anaconda или другого окружения в
`PATH`.

:::note
Рекомендуется перезапустить терминал после установки, если `nessy` сразу не появляется в PATH. Если установка не удалась, обратитесь к [ручной установке](./quickstart#ручная-установка) в руководстве по быстрому старту. Для автономной установки загрузите архив релиза и запустите установщик с `--archive PATH`; держите `SHA256SUMS` рядом с архивом.
:::

### Начните использовать Nessy CLI:

```bash
cd your-project
nessy
```

Выберите аутентификацию DP Authentification и следуйте инструкциям для входа в систему. Затем начните с изучения своей кодовой базы. Попробуйте одну из этих команд:

```
what does this project do?
```

При первом использовании вам будет предложено войти в систему. Вот и всё! [Продолжите с Быстрым стартом (5 минут) →](./quickstart.md)

:::note
Смотрите [устранение неполадок](./work/support/troubleshooting.md), если у вас возникли проблемы.
:::

## Что делает Nessy CLI для вас

- **Создавайте функции по описанию**: Расскажите Nessy CLI, что вы хотите создать, на обычном языке. Он составит план, напишет код и убедится, что он работает.
- **Отладка и исправление ошибок**: Опишите ошибку или вставьте сообщение об ошибке. Nessy CLI проанализирует вашу кодовую базу, определит проблему и реализует исправление.
- **Навигация по любой кодовой базе**: Задавайте любые вопросы о кодовой базе или документации вашей команды и получайте обдуманные ответы. Nessy CLI поддерживает осведомлённость о всей структуре вашего проекта, может находить актуальную информацию в интернете, а с помощью [MCP](./work/features/mcp.md) может получать данные из внешних источников, таких как Sage, Wiki, GitLab, Jira.
- **Автоматизация утомительных задач**: Исправляйте мелкие проблемы с линтером, разрешайте конфликты слияния и пишите заметки о релизе. Делайте всё это одной командой на своих разработческих машинах или автоматически в CI.
- **[Followup-предложения](./work/features/followup-suggestions.md)**: Nessy CLI предсказывает, что вы хотите ввести дальше, и показывает это как ghost-текст. Нажмите Tab для принятия или продолжайте ввод для отклонения.

## Почему разработчикам и аналитикам нравится Nessy CLI

- **Работает в вашем терминале**: Не ещё одно окно чата. Не ещё одна IDE. Nessy CLI встречается там, где вы уже работаете, с инструментами, которые вы уже любите.
- **Предпринимает действия**: Nessy CLI может напрямую редактировать файлы, запускать команды и создавать коммиты. Нужно больше? [MCP](./work/features/mcp.md) позволяет Nessy CLI читать ваши проектные документы, читать ваши задачи в Jira или использовать _ваши_ пользовательские инструменты разработки.
- **Философия Unix**: Nessy CLI компонуем и скриптуем. `tail -f app.log | nessy -p "Сообщи мне в Time, если в этом потоке лога появятся аномалии"` _работает_. Ваш CI может запускать `nessy -p "Если есть новые текстовые строки, переведи их на французский и создай MR для проверки @lang-fr-team"`.
