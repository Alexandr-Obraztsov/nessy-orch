# JetBrains IDEs — Альтернатива нативного подключения

##### IntelliJ

1. Скачать последнюю релизную версию плагина
   👉 [**Скачать release latest**](https://s3-msk.tinkoff.ru/nestor-companion/release/jetbrains/nessy-intellij-ide-companion-latest-since-233.zip)

   👉 [**Скачать последнюю нерелизную сборку**](https://s3-msk.tinkoff.ru/nestor-companion/jetbrains/nessy-intellij-ide-companion-latest.zip)

2. В IntelliJ IDEA:
   **File → Settings → Plugins → ⚙️ (Install plugin from disk)**
   Выберите скачанный `.zip` файл.

3. Перезапустите IDE.
