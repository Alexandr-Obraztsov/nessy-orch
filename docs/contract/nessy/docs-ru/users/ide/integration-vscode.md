# Visual Studio Code

> Расширение VS Code (Beta) позволяет видеть изменения Nessy в реальном времени через нативный графический интерфейс, встроенный непосредственно в вашу IDE, что упрощает доступ и взаимодействие с Nessy CLI.

### Возможности

- **Нативный опыт в IDE**: Выделенная боковая панель Nessy CLI, доступная через иконку Nessy
- **Режим автопринятия правок**: Автоматическое применение изменений Nessy по мере их внесения
- **Управление файлами**: Упоминание файлов через @ или прикрепление файлов и изображений с помощью системного выбора файлов
- **История разговоров**: Доступ к прошлым разговорам
- **Несколько сессий**: Одновременный запуск нескольких сессий Nessy CLI

### Требования

- VS Code 1.85.0 или выше

### Установка

1. Скачать последний релиз плагина
   👉 [**Скачать последний релиз**](https://s3-msk.tinkoff.ru/nestor-companion/vscode/nessy-cli-vscode-ide-companion-latest.vsix)

2. В VSCode:
   **View → Extensions → ⚙️ (Install from VSIX)**

## Устранение неполадок

### Расширение не устанавливается

- Убедитесь, что у вас VS Code 1.85.0 или выше
- Проверьте, что VS Code имеет разрешение на установку расширений

### Nessy CLI не отвечает

- Проверьте ваше интернет-соединение
- Начните новый разговор, чтобы проверить, сохраняется ли проблема
