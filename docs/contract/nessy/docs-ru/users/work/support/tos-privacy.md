# Nessy CLI: Уведомление об условиях обслуживания и конфиденциальности

Nessy CLI — это инструмент ИИ-ассистента для кодирования с открытым исходным кодом, поддерживаемый командой Nessy CLI. Этот документ описывает условия обслуживания и политики конфиденциальности, которые применяются при использовании методов аутентификации Nessy CLI и сервисов моделей ИИ.

## Как определить ваш метод аутентификации

Nessy CLI поддерживает два основных метода аутентификации для доступа к моделям ИИ. Ваш метод аутентификации определяет, какие условия обслуживания и политики конфиденциальности применяются к вашему использованию:

1. **Nessy DP Authentification** — Вход с вашей корпоративной учётной записью
2. **OpenAI-совместимое API** — Использование API-ключей от различных провайдеров моделей ИИ (всегда используйте llm-proxy)

Для каждого метода аутентификации могут применяться различные условия обслуживания и уведомления о конфиденциальности в зависимости от основного провайдера сервиса.

## 1. Если вы используете аутентификацию Nessy DP Authentification

Для деталей о настройке аутентификации, квотах и поддерживаемых функциях смотрите [Настройка аутентификации](../configuration/settings.md).

## 2. Если вы используете аутентификацию OpenAI-совместимого API

Когда вы аутентифицируетесь используя API-ключи от OpenAI-совместимых провайдеров, применимые условия обслуживания и уведомление о конфиденциальности зависят от вашего выбранного провайдера.

:::important
При использовании аутентификации OpenAI-совместимого API вы подчиняетесь условиям и политикам конфиденциальности вашего выбранного провайдера API, а не условиям Nessy CLI. Пожалуйста, просмотрите документацию вашего провайдера для конкретных деталей об использовании данных, хранении и практиках конфиденциальности.
:::

Nessy CLI поддерживает различные OpenAI-совместимые провайдеры. Пожалуйста, обратитесь к условиям обслуживания и политике конфиденциальности вашего специфичного провайдера для детальной информации.

## Статистика использования и телеметрия

Nessy CLI может собирать анонимную статистику использования и данные [телеметрии](../../../developers/work/development/telemetry.md) для улучшения пользовательского опыта и качества продукта. Этот сбор данных является опциональным и может контролироваться через настройки конфигурации.

### Какие данные собираются

При включении Nessy CLI может собирать:

- Анонимную статистику использования (выполненные команды, метрики производительности)
- Отчёты об ошибках и данные о сбоях
- Паттерны использования функций

### Сбор данных по методу аутентификации

- **DP Authentification:** Статистика использования регулируется политикой конфиденциальности Nessy.
- **OpenAI-совместимое API:** Никакие дополнительные данные не собираются Nessy CLI сверх того, что собирает ваш выбранный провайдер API.

## Часто задаваемые вопросы (FAQ)

### 1. Используется ли мой код, включая подсказки и ответы, для обучения моделей ИИ?

Используется ли ваш код, включая подсказки и ответы, для обучения моделей ИИ, зависит от вашего метода аутентификации и специфичного провайдера сервиса ИИ, который вы используете:

- **OpenAI-совместимое API**: Использование данных полностью зависит от вашего выбранного провайдера API. Каждый провайдер имеет свои собственные политики использования данных. Пожалуйста, просмотрите политику конфиденциальности и условия обслуживания вашего специфичного провайдера.

**Важно**: Сам Nessy CLI не использует ваши подсказки, код или ответы для обучения моделей. Любое использование данных для обучения регулируется политиками провайдера сервиса ИИ, с которым вы аутентифицируетесь.

### 2. Что такое статистика использования и что контролирует отказ?

Настройка **статистики использования** контролирует опциональный сбор данных Nessy CLI для улучшения пользовательского опыта и качества продукта.

При включении Nessy CLI может собирать:

- Анонимную телеметрию (выполненные команды, метрики производительности, использование функций)
- Отчёты об ошибках и данные о сбоях
- Общие паттерны использования

**Что НЕ собирается Nessy CLI:**

- Содержимое вашего кода
- Подсказки, отправленные моделям ИИ
- Ответы от моделей ИИ
- Личная информация

Настройка статистики использования контролирует только сбор данных самим Nessy CLI. Она не влияет на то, какие данные ваш выбранный провайдер сервиса ИИ (Nessy, OpenAI и т.д.) может собирать согласно их собственным политикам конфиденциальности.

### 3. Как переключиться между методами аутентификации?

Вы можете переключиться между аутентификацией Nessy DP-Auth и OpenAI-совместимым API в любое время:

1. **Во время запуска**: Выберите предпочитаемый метод аутентификации при запросе
2. **Внутри CLI**: Используйте команду `/auth` для переконфигурирования вашего метода аутентификации
3. **Переменные окружения**: Настройте файлы `.env` для автоматической аутентификации OpenAI-совместимого API

Для детальных инструкций смотрите документацию [Настройка аутентификации](../configuration/settings.md#environment-variables-for-api-access).
