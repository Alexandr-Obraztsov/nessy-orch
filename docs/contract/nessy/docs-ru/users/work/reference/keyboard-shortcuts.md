# Клавиатурные сокращения Nessy CLI

Этот документ перечисляет доступные клавиатурные сокращения в Nessy CLI.

## Общие

| Сокращение                     | Описание                                                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| `Esc`                          | Закрыть диалоги и предложения.                                                                                                        |
| `Ctrl+C`                       | Отменить текущий запрос и очистить ввод. Нажмите дважды для выхода из приложения.                                                     |
| `Ctrl+D`                       | Выйти из приложения, если ввод пуст. Нажмите дважды для подтверждения.                                                                |
| `Ctrl+L`                       | Очистить экран.                                                                                                                       |
| `Ctrl+O`                       | Переключить отображение консоли отладки.                                                                                              |
| `Ctrl+S`                       | Позволяет длинным ответам печататься полностью, отключая усечение. Используйте прокрутку вашего терминала для просмотра всего вывода. |
| `Ctrl+T`                       | Переключить отображение описаний инструментов.                                                                                        |
| `Shift+Tab` (`Tab` на Windows) | Циклически переключать режимы одобрения (`plan` → `default` → `auto-edit`)                                                            |

## Ввод подсказки

| Сокращение                                         | Описание                                                                                                                                     |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `!`                                                | Переключить режим оболочки, когда ввод пуст.                                                                                                 |
| `?`                                                | Переключить отображение клавиатурных сокращений, когда ввод пуст.                                                                            |
| `\` (в конце строки) + `Enter`                     | Вставить новую строку.                                                                                                                       |
| `Down Arrow`                                       | Навигация вниз по истории ввода.                                                                                                             |
| `Enter`                                            | Отправить текущую подсказку.                                                                                                                 |
| `Meta+Delete` / `Ctrl+Delete`                      | Удалить слово справа от курсора.                                                                                                             |
| `Tab`                                              | Автодополнение текущего предложения, если оно существует.                                                                                    |
| `Up Arrow`                                         | Навигация вверх по истории ввода.                                                                                                            |
| `Ctrl+A` / `Home`                                  | Переместить курсор в начало строки.                                                                                                          |
| `Ctrl+B` / `Left Arrow`                            | Переместить курсор на один символ влево.                                                                                                     |
| `Ctrl+C`                                           | Очистить подсказку ввода                                                                                                                     |
| `Esc` (двойное нажатие)                            | Очистить подсказку ввода.                                                                                                                    |
| `Ctrl+D` / `Delete`                                | Удалить символ справа от курсора.                                                                                                            |
| `Ctrl+E` / `End`                                   | Переместить курсор в конец строки.                                                                                                           |
| `Ctrl+F` / `Right Arrow`                           | Переместить курсор на один символ вправо.                                                                                                    |
| `Ctrl+H` / `Backspace`                             | Удалить символ слева от курсора.                                                                                                             |
| `Ctrl+K`                                           | Удалить от курсора до конца строки.                                                                                                          |
| `Ctrl+Left Arrow` / `Meta+Left Arrow` / `Meta+B`   | Переместить курсор на одно слово влево.                                                                                                      |
| `Ctrl+N`                                           | Навигация вниз по истории ввода.                                                                                                             |
| `Ctrl+P`                                           | Навигация вверх по истории ввода.                                                                                                            |
| `Ctrl+R`                                           | Обратный поиск по истории ввода/оболочки.                                                                                                    |
| `Ctrl+Y`                                           | Повторить последний неудачный запрос.                                                                                                        |
| `Ctrl+Right Arrow` / `Meta+Right Arrow` / `Meta+F` | Переместить курсор на одно слово вправо.                                                                                                     |
| `Ctrl+U`                                           | Удалить от курсора до начала строки.                                                                                                         |
| `Ctrl+V` (Windows: `Alt+V`)                        | Вставить содержимое буфера обмена. Если буфер обмена содержит изображение, оно будет сохранено и ссылка на него будет вставлена в подсказку. |
| `Ctrl+W` / `Meta+Backspace` / `Ctrl+Backspace`     | Удалить слово слева от курсора.                                                                                                              |
| `Ctrl+X` / `Meta+Enter`                            | Открыть текущий ввод во внешнем редакторе.                                                                                                   |

## Предложения

| Сокращение      | Описание                         |
| --------------- | -------------------------------- |
| `Down Arrow`    | Навигация вниз по предложениям.  |
| `Tab` / `Enter` | Принять выбранное предложение.   |
| `Up Arrow`      | Навигация вверх по предложениям. |

## Выбор кнопок

| Сокращение         | Описание                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------- |
| `Down Arrow` / `j` | Переместить выделение вниз.                                                                   |
| `Enter`            | Подтвердить выделение.                                                                        |
| `Up Arrow` / `k`   | Переместить выделение вверх.                                                                  |
| `1-9`              | Выбрать элемент по его номеру.                                                                |
| (multi-digit)      | Для элементов с номерами больше 9, быстро нажмите цифры для выбора соответствующего элемента. |

## Интеграция с IDE

| Сокращение | Описание                    |
| ---------- | --------------------------- |
| `Ctrl+G`   | Просмотреть контекст от IDE |
