# Рендеринг Markdown

Nessy CLI отображает распространённые структуры Markdown напрямую в TUI, чтобы ответы модели было легче просматривать, не покидая терминал. Рендерер разработан так, чтобы исходный код оставался доступным, особенно для визуальных блоков, таких как диаграммы Mermaid и математические формулы LaTeX.

## Режимы Render и Raw

По умолчанию Markdown отображается в режиме `render`. Поддерживаемые блоки отображаются как визуальные превью, где это возможно:

- fenced-блоки кода Mermaid
- таблицы Markdown
- списки задач
- цитаты
- встроенная и блочная математика LaTeX
- fenced-блоки кода с подсветкой синтаксиса

Нажмите `Alt/Option+M`, чтобы переключать текущую сессию между режимами. На macOS терминал должен отправлять Option как Meta для этого сочетания клавиш; иначе Option+M обрабатывается как обычный текстовый ввод.

- `render`: показывать богатые терминальные превью для поддерживаемого Markdown.
- `raw`: показывать ориентированный на исходный код Markdown для визуальных блоков, таких как Mermaid, таблицы и LaTeX.

Чтобы запускать Nessy CLI в режиме raw по умолчанию, установите `ui.renderMode`:

```json
{
  "ui": {
    "renderMode": "raw"
  }
}
```

Принимаемые значения — `"render"` и `"raw"`. Сочетание клавиш меняет только просмотр текущей сессии; оно не перезаписывает файл настроек.

## Mermaid

Fenced-блоки кода mermaid отображаются визуально в режиме render. TUI использует многоуровневую стратегию:

1. Если включено и поддерживается, Nessy CLI запрашивает Mermaid CLI (mmdc) отрендерить диаграмму в PNG и отправляет её в протокол изображений терминала.
2. Если изображения терминала недоступны, но chafa установлен, тот же PNG может быть преобразован в блочную графику ANSI.
3. Иначе Nessy CLI возвращается к терминальному wireframe или компактному текстовому превью.
4. Если тип диаграммы Mermaid не может быть превьюирован, Nessy CLI показывает исходный fenced-код вместо того, чтобы скрывать его за заполнителем.

Рендеринг изображений Mermaid отключён по умолчанию, потому что он требует внешних рендереров и поддержки изображений терминалом. Включите его с помощью:

```bash
NESSY_CLI_MERMAID_IMAGE_RENDERING=1 nessy
```

Необязательные переменные окружения:

| Переменная                                  | Описание                                                                                           |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `NESSY_CLI_MERMAID_IMAGE_RENDERING=1`       | Включает внешний рендеринг изображений Mermaid.                                                    |
| `NESSY_CLI_DISABLE_MERMAID_IMAGES=1`        | Отключает рендеринг изображений Mermaid, даже когда включено в другом месте.                       |
| `NESSY_CLI_MERMAID_IMAGE_PROTOCOL=kitty`    | Принудительно выводит протокол Kitty. Полезно для терминалов, таких как Kitty и Ghostty.           |
| `NESSY_CLI_MERMAID_IMAGE_PROTOCOL=iterm2`   | Запрашивает встроенные изображения iTerm2. Интерактивный рендеринг TUI возвращается к тексту/ANSI. |
| `NESSY_CLI_MERMAID_IMAGE_PROTOCOL=off`      | Отключает протоколы изображений терминала и разрешает текстовый fallback или chafa.                |
| `NESSY_CLI_MERMAID_MMD_CLI=/path/to/mmdc`   | Использует конкретный исполняемый файл Mermaid CLI.                                                |
| `NESSY_CLI_MERMAID_ALLOW_NPX=1`             | Разрешает Nessy CLI запускать npx @mermaid-js/mermaid-cli, когда mmdc не установлен.               |
| `NESSY_CLI_MERMAID_ALLOW_LOCAL_RENDERERS=1` | Разрешает локальные бинарники рендереров проекта под node_modules/.bin.                            |
| `NESSY_CLI_MERMAID_RENDER_WIDTH=1200`       | Переопределяет ширину рендеринга PNG.                                                              |
| `NESSY_CLI_MERMAID_RENDER_TIMEOUT_MS=10000` | Переопределяет таймаут внешнего рендеринга, ограничено 60000 мс.                                   |
| `NESSY_CLI_MERMAID_CELL_ASPECT_RATIO=0.5`   | Настраивает подгонку строк изображения под геометрию ячеек шрифта терминала.                       |

Первый рендеринг изображения может быть медленным, особенно когда npx нужно разрешить или загрузить Mermaid CLI. Во время потоковой передачи Nessy CLI показывает ограниченное текстовое превью и пытается отрендерить изображение только после завершения ответа модели.

### Копирование исходного кода Mermaid

Каждый отрендеренный блок Mermaid включает подсказку об источнике, такую как:

```text
Mermaid flowchart (TD) · source: /copy mermaid 1
```

Используйте эти команды для копирования исходного кода Mermaid из последнего ответа ИИ:

| Команда                | Поведение                                    |
| ---------------------- | -------------------------------------------- |
| `/copy mermaid`        | Копирует последний блок Mermaid.             |
| `/copy mermaid 1`      | Копирует первый блок Mermaid.                |
| `/copy code mermaid`   | Копирует последний fenced-блок кода mermaid. |
| `/copy code mermaid 1` | Копирует первый fenced-блок кода mermaid.    |

`/copy code 1` считает все fenced-блоки кода, а не только блоки Mermaid. Используйте `/copy mermaid N`, когда вам нужна последовательность, специфичная для Mermaid, показанная в отрендеренном заголовке.

## Математика LaTeX

Nessy CLI поддерживает базовый встроенный и блочный рендеринг LaTeX в терминале:

```markdown
Встроенная математика: $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$

$$
\sum_{n=1}^{\infty} 1/n^2 = \pi^2/6
$$
```

Рендерер фокусируется на распространённых символах и читаемом выводе терминала. Это не полноценный движок TeX; сложные макеты, такие как матрицы, выровненные уравнения и большие вложенные выражения, могут быть упрощены.

Выражения $...$ намеренно ограничены 1024 символами на строку, чтобы неправильно сформированный или очень большой сгенерированный Markdown не мог заблокировать рендеринг терминала. Более длинные формулы остаются видимыми как исходный текст и всё ещё могут быть скопированы из режима raw или оригинального ответа.

### Копирование исходного кода LaTeX

Используйте эти команды для копирования исходного кода LaTeX из последнего ответа ИИ:

| Команда                | Поведение                                   |
| ---------------------- | ------------------------------------------- |
| `/copy latex`          | Копирует последнее блочное выражение LaTeX. |
| `/copy latex 2`        | Копирует второе блочное выражение.          |
| `/copy latex inline`   | Копирует последнее встроенное выражение.    |
| `/copy latex inline 2` | Копирует второе встроенное выражение.       |
| `/copy inline-latex 2` | Псевдоним для `/copy latex inline 2`.       |

Встроенный LaTeX не показывает подсказку копирования для каждого выражения в отрендеренном тексте, чтобы не делать текст шумным. Переключитесь в режим `raw` с помощью `Alt/Option+M`, когда хотите проверить встроенный исходный код на месте; на macOS это требует ввода терминала Option-as-Meta.

## Общее копирование кода

Команда `/copy code` читает fenced-блоки кода из последнего ответа Markdown ИИ:

| Команда                 | Поведение                                |
| ----------------------- | ---------------------------------------- |
| `/copy code`            | Копирует последний fenced-блок кода.     |
| `/copy code 2`          | Копирует второй fenced-блок кода.        |
| `/copy code typescript` | Копирует последний блок кода typescript. |
| `/copy code mermaid 1`  | Копирует первый блок кода mermaid.       |

## Текущие ограничения

- Рендеринг изображений Mermaid зависит от Mermaid CLI плюс поддержка изображений терминалом.
- Асинхронная вставка встроенных изображений iTerm2 отключена в TUI, потому что протокол привязан к позиции курсора; используйте Kitty/Ghostty или fallback ANSI для интерактивных превью изображений.
- Рендеринг wireframe Mermaid — это читаемое терминальное превью, а не полноценный движок макетов Mermaid.
- Режим raw глобален для отрендеренных блоков Markdown; это не переключатель для каждого блока.
- Рендеринг LaTeX охватывает распространённые символы и выражения, а не полный макет TeX.
- Команды копирования исходного кода работают с последним ответом ИИ.
