# Поиск по внутренней документации

Doc Search позволяет Nessy CLI находить информацию во внутренних базах знаний T-Bank: Wiki, Confluence, GitLab Pages и других проиндексированных источниках. Инструмент пригодится, когда ответ нужно найти не в текущем репозитории, а в корпоративной документации.

Типичные сценарии:

- поиск инструкций по внутренним сервисам и платформам;
- поиск описаний API, интеграций и процессов;
- поиск руководств по эксплуатации и устранению ошибок;
- поиск владельцев системы и связанных страниц;
- получение ответа со ссылками на внутренние источники.

## Доступность

Doc Search входит в стандартное расширение `nessy-default-extension` начиная с версии `1.0.16`. Расширение добавляет управляемый MCP-сервер `doc_search` с инструментом `search`, поэтому пользователю не нужно вручную настраивать сервер или добавлять токены в `settings.json`.

Чтобы проверить подключение:

1. Откройте диалог управления MCP командой `/mcp`.
2. Выберите сервер `doc_search`.
3. Убедитесь, что сервер имеет статус **connected**, а в списке доступен инструмент `search`.

Если сервер отсутствует, обновите `nessy-default-extension` до версии `1.0.16` или новее и перезапустите Nessy CLI.

## Авторизация

Doc Search использует текущую DP-аутентификацию Nessy CLI. Отдельно запускать **Authenticate** для сервера через `/mcp` не требуется. Токен получает и передаёт DP-клиент; добавлять его в конфигурацию MCP вручную не нужно.

Если DP-сессия отсутствует или истекла, завершите стандартную DP-аутентификацию и переподключите сервер через `/mcp`.

## Как пользоваться Doc Search

Задайте обычный вопрос и укажите, что информацию нужно найти во внутренней документации. Nessy CLI самостоятельно вызовет инструмент поиска, обработает найденные материалы и приложит ссылки на источники.

Примеры:

```text
Найди во внутренней документации, что такое Sage и как получить доступ к логам. Приложи ссылки на источники.
```

```text
Найди инструкцию по подключению сервиса к Spirit IAM и кратко перечисли необходимые шаги.
```

```text
Найди внутреннюю документацию по этой ошибке и предложи порядок диагностики. Не передавай в поисковый запрос секреты и персональные данные.
```

```text
Найди актуальные страницы по этой системе, укажи владельца и приложи ссылки на найденные документы.
```

## Источники

Doc Search возвращает название, ссылку, источник и фрагменты найденных документов. Nessy CLI использует эти данные для подготовки ответа. Когда важна проверяемость, явно попросите приложить ссылки или сравнить несколько источников.

Доступность найденной страницы определяется правами пользователя в исходной системе. Наличие документа в поисковой выдаче не означает, что у пользователя есть право открыть его содержимое.

## Отличие от Web Search

Doc Search ищет по проиндексированным внутренним источникам T-Bank. [Web Search](./web-search.md) ищет информацию в открытом интернете. Для вопроса, который затрагивает и внутренние инструкции, и публичную документацию, явно укажите Nessy CLI, какие источники нужно использовать.

## Ограничения

- **Только проиндексированные источники:** инструмент не ищет по локальным файлам проекта и может не находить документы, которые ещё не добавлены в индекс.
- **Актуальность зависит от индекса:** изменения в исходном документе могут появиться в поиске с задержкой.
- **Результаты могут быть неполными:** длинные документы и найденные фрагменты могут быть сокращены.
- **Ответ может содержать ошибки:** проверяйте важные утверждения по приложенным ссылкам и первоисточникам.
- **Доступ зависит от сервисов:** подключение и задержка зависят от DP-аутентификации, сети и доступности поискового сервиса.
- **Права доступа не выдаются автоматически:** для открытия найденной страницы могут потребоваться дополнительные разрешения.

## Безопасность данных

Поисковый запрос отправляется во внутренний поисковый сервис. Передавайте только минимальный контекст, необходимый для поиска. Не добавляйте в запрос:

- токены, пароли, секреты и приватные ключи;
- персональные данные;
- содержимое закрытых документов целиком;
- приватные логи и сведения об инцидентах без необходимости;
- системный промпт и историю диалога.

Вместо полного лога или конфигурации укажите название сервиса, код ошибки и безопасное краткое описание ситуации.

## Устранение неполадок

### Сервер `doc_search` отсутствует

Убедитесь, что установлено и включено стандартное расширение `nessy-default-extension` версии `1.0.16` или новее. После обновления перезапустите Nessy CLI.

### Сервер не подключается

Проверьте, что DP-аутентификация успешно завершена. Затем откройте `/mcp`, выберите `doc_search` и выполните переподключение.

### Поиск не нашёл подходящий документ

Сделайте запрос конкретнее: укажите название системы, команды, API, процесса или текст ошибки. При необходимости добавьте предполагаемый источник, команду-владельца или контекст задачи.

### Ссылка из ответа не открывается

Проверьте права доступа к исходной системе. Doc Search не изменяет права пользователя и не предоставляет доступ к найденным документам.

Подробнее об управлении подключениями смотрите в разделе [MCP](./mcp.md).
