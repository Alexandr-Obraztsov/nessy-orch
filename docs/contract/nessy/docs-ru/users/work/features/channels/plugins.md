# Кастомные плагины каналов

Вы можете расширить систему каналов кастомными адаптерами платформ, упакованными как [расширения](../../extension/introduction.md). Это позволяет подключить Nessy CLI к любой платформе обмена сообщениями, webhook или кастомному транспорту.

## Как это работает

Плагины каналов загружаются при старте из активных расширений. Когда запускается `nessy channel start`, он:

1. Сканирует все включённые расширения на наличие записей `channels` в их `nessy-extension.json`
2. Динамически импортирует entry point каждого канала
3. Регистрирует тип канала, чтобы на него можно было ссылаться в `settings.json`
4. Создаёт экземпляры каналов, используя factory функцию плагина

Ваш кастомный канал получает полный shared pipeline бесплатно: sender gating, group policies, session routing, slash команды, crash recovery и ACP bridge к агенту.

## Установка кастомного канала

Установите расширение, предоставляющее плагин канала:

```bash
# Из локального пути (для разработки или приватных плагинов)
nessy extensions install /path/to/my-channel-extension

# Или link для разработки (изменения отражаются немедленно)
nessy extensions link /path/to/my-channel-extension
```

## Конфигурация кастомного канала

Добавьте запись канала в `~/.nessy/settings.json`, используя кастомный тип, предоставленный расширением:

```json
{
  "channels": {
    "my-bot": {
      "type": "my-platform",
      "apiKey": "$MY_PLATFORM_API_KEY",
      "senderPolicy": "open",
      "cwd": "/path/to/project"
    }
  }
}
```

`type` должен совпадать с типом канала, зарегистрированным установленным расширением. Проверьте документацию расширения на предмет того, какие специфичные для плагина поля требуются (например, `apiKey`, `webhookUrl`).

Все стандартные опции каналов работают с кастомными каналами:

| Опция          | Описание                                        |
| -------------- | ----------------------------------------------- |
| `senderPolicy` | `allowlist`, `pairing` или `open`               |
| `allowedUsers` | Статический allowlist ID отправителей           |
| `sessionScope` | `user`, `thread` или `single`                   |
| `cwd`          | Working directory для агента                    |
| `instructions` | Добавляется в начало первого сообщения в сессии |
| `model`        | Override модели для канала                      |
| `groupPolicy`  | `disabled`, `allowlist` или `open`              |
| `groups`       | Настройки на группу                             |

См. [Обзор](./overview.md) для деталей по каждой опции.

## Запуск канала

```bash
# Запустить все каналы, включая кастомные
nessy channel start

# Запустить только ваш кастомный канал
nessy channel start my-bot
```

## Что вы получаете бесплатно

Кастомные каналы автоматически поддерживают всё, что делают встроенные каналы:

- **Sender policies** — Контроль доступа `allowlist`, `pairing` и `open`
- **Group policies** — Настройки на группу с опциональным @mention gating
- **Session routing** — Сессии на пользователя, на тред или одна общая сессия
- **DM pairing** — Полный flow pairing code для неизвестных пользователей
- **Slash команды** — `/help`, `/clear`, `/status` работают из коробки
- **Кастомные инструкции** — Добавляются в начало первого сообщения в каждой сессии
- **Crash recovery** — Автоматический рестарт с сохранением сессии
- **Per-session serialization** — Сообщения queued для предотвращения race conditions
