# Контекстные подсказки

Nessy CLI включает систему контекстных подсказок, которая помогает вам открывать функции и оставаться в курсе состояния сессии.

## Подсказки при запуске

Каждый раз, когда вы запускаете Nessy CLI, в заголовке показывается подсказка. Подсказки выбираются сначала по приоритету, затем чередуются между сессиями с использованием планирования LRU (least-recently-used) среди подсказок одного приоритета, поэтому вы видите другую подсказку каждый раз.

Новые пользователи видят подсказки, сфокусированные на онбординге, во время своих первых сессий:

| Сессии | Примеры подсказок                                      |
| ------ | ------------------------------------------------------ |
| < 5    | Slash-команды (`/`), автодополнение Tab                |
| < 10   | `NESSY.md` контекст проекта, `--continue` / `--resume` |
| < 15   | Команды оболочки с префиксом `!`                       |

После этого подсказки чередуются через общие функции, такие как `/compress`, `/approval-mode`, `/insight`, `/btw` и другие.

## Подсказки после ответа

Во время разговора Nessy CLI отслеживает использование вашего контекстного окна и показывает подсказки, когда может потребоваться действие:

| Использование контекста | Условие                             | Подсказка                                                       |
| ----------------------- | ----------------------------------- | --------------------------------------------------------------- |
| 50-80%                  | После нескольких подсказок в сессии | Предлагает `/compress` для освобождения контекста               |
| 80-95%                  | —                                   | Предупреждает, что контекст заполняется                         |
| >= 95%                  | —                                   | Срочно: запустите `/compress` сейчас или `/new` для продолжения |

Подсказки после ответа имеют cooldown'ы для каждой подсказки, чтобы избежать повторений.

## История подсказок

История отображения подсказок сохраняется в `~/.nessy/tip_history.json`. Этот файл отслеживает:

- Количество сессий (используется для выбора подсказок нового пользователя)
- Какие подсказки были показаны и когда (используется для LRU-чередования и cooldown)

Вы можете безопасно удалить этот файл для сброса истории подсказок.

## Отключение подсказок

Чтобы скрыть все подсказки (как при запуске, так и после ответа), установите `ui.hideTips` в `true` в `~/.nessy/settings.json`:

```json
{
  "ui": {
    "hideTips": true
  }
}
```

Вы также можете переключить это в диалоге настроек через команду `/settings`.

Подсказки также автоматически скрываются, когда включён режим экранного диктора.
