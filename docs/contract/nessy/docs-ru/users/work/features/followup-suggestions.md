# Подсказки продолжения (Followup Suggestions)

Nessy CLI может предсказывать, что вы захотите ввести дальше, и показывать это как полупрозрачный текст в области ввода. Эта функция использует LLM-запрос для анализа контекста разговора и генерации естественного следующего шага.

Эта функция работает end-to-end в Nessy CLI. В WebUI хуки и UI-механизмы доступны, но хост-приложения должны запускать генерацию подсказок и подключать состояние продолжения для появления подсказок.

## Как это работает

После завершения ответа Nessy CLI подсказка появляется как тусклый текст в области ввода после короткой задержки (~300 мс). Например, после исправления бага вы можете увидеть:

```
> запустить тесты
```

Подсказка генерируется отправкой истории разговора модели, которая предсказывает, что вы логично введёте дальше. Если ответ содержит явную подсказку (например, `Tip: type post comments to publish findings`), предлагаемое действие извлекается автоматически.

## Принятие подсказок

| Клавиша           | Действие                                 |
| ----------------- | ---------------------------------------- |
| `Tab`             | Принять подсказку и заполнить её в ввод  |
| `Enter`           | Принять подсказку и отправить немедленно |
| `Right Arrow`     | Принять подсказку и заполнить её в ввод  |
| Любой ввод текста | Отклонить подсказку и печатать нормально |

## Когда появляются подсказки

Подсказки генерируются, когда выполняются все следующие условия:

- Модель завершила свой ответ (не во время потоковой передачи)
- Произошло как минимум 2 хода модели в разговоре
- В последнем ответе нет ошибок
- Нет ожидающих диалогов подтверждения (например, подтверждение оболочки, разрешения)
- Режим утверждения не установлен в `plan`
- Функция включена в настройках (включено по умолчанию)

Подсказки не появляются в неинтерактивном режиме (например, headless/SDK режим).

Подсказки автоматически отклоняются, когда:

- Вы начинаете печатать
- Начинается новый ход модели
- Подсказка принята

## Быстрая модель

По умолчанию для подсказок используется та же модель, что и для основного разговора. Для более быстрых и дешёвых подсказок настройте выделенную быструю модель:

### Через команду

```
/model --fast qwen3-coder-flash
```

Или используйте `/model --fast` (без имени модели) для открытия диалога выбора.

### Через settings.json

```json
{
  "fastModel": "qwen3-coder-flash"
}
```

Быстрая модель используется для подсказок продолжения и опережающего выполнения. Когда не настроена, в качестве резерва используется модель основного разговора.

Режим мышления/рассуждения автоматически отключается для всех фоновых задач (генерация подсказок и опережающее выполнение), независимо от конфигурации мышления вашей основной модели. Это позволяет избежать траты токенов на внутренние рассуждения, которые не нужны для этих задач.

## Конфигурация

Эти настройки могут быть настроены в `settings.json`:

| Настройка                      | Тип     | По умолчанию | Описание                                                                       |
| ------------------------------ | ------- | ------------ | ------------------------------------------------------------------------------ |
| `ui.enableFollowupSuggestions` | boolean | `true`       | Включить или отключить последующие подсказки                                   |
| `ui.enableCacheSharing`        | boolean | `true`       | Использовать разделяемые кэш-запросы для снижения стоимости (экспериментально) |
| `ui.enableSpeculation`         | boolean | `false`      | Опережающее выполнение подсказок перед отправкой (экспериментально)            |
| `fastModel`                    | string  | `""`         | Модель для подсказок продолжения и опережающего выполнения                     |

### Пример

```json
{
  "fastModel": "qwen3-coder-flash",
  "ui": {
    "enableFollowupSuggestions": true,
    "enableCacheSharing": true
  }
}
```

## Мониторинг

Использование модели подсказок отображается в выводе `/stats`, показывая токены, потреблённые быстрой моделью для генерации подсказок.

Быстрая модель также показывается в выводе `/about` под "Fast Model".

## Качество подсказок

Подсказки проходят через фильтры качества, чтобы обеспечить их полезность:

- Должны быть 2-12 слов (CJK: 2-30 символов), менее 100 символов всего
- Не могут быть оценочными («выглядит хорошо», «спасибо»)
- Не могут использовать голос ИИ («Позвольте мне...», «Я...»)
- Не могут быть несколькими предложениями или содержать форматирование (markdown, новые строки)
- Не могут быть мета-комментариями («нечего предложить», «молчание»)
- Не могут быть сообщениями об ошибках или помеченными префиксами («Подсказка: ...»)
- Однословные подсказки разрешены только для распространённых команд (yes, commit, push и т.д.)
- Slash-команды (например, `/commit`) всегда разрешены как однословные подсказки
