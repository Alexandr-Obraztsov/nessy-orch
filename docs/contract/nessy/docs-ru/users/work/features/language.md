# Интернационализация (i18n) и язык

Nessy CLI построен для многоязычных рабочих процессов: поддерживает локализацию UI (i18n/l10n) в CLI, позволяет вам выбирать язык вывода ассистента и позволяет настраивать пользовательские языковые пакеты UI.

## Обзор

С точки зрения пользователя "интернационализация" Nessy CLI охватывает несколько слоёв:

| Возможность / Настройка             | Что контролирует                                                  | Где хранится                  |
| ----------------------------------- | ----------------------------------------------------------------- | ----------------------------- |
| `/language ui`                      | Текст UI терминала (меню, системные сообщения, подсказки)         | `~/.nessy/settings.json`      |
| `/language output`                  | Язык, на котором AI отвечает (предпочтение вывода, не перевод UI) | `~/.nessy/output-language.md` |
| Пользовательские языковые пакеты UI | Переопределяет/расширяет встроенные переводы UI                   | `~/.nessy/locales/*.js`       |

## Язык UI

Это слой локализации UI (i18n/l10n) CLI: контролирует язык меню, подсказок и системных сообщений.

### Установка языка UI

Используйте команду `/language ui`:

```bash
/language ui zh-CN    # Китайский
/language ui en-US    # Английский
/language ui ru-RU    # Русский
/language ui de-DE    # Немецкий
/language ui ja-JP    # Японский
```

Псевдонимы также поддерживаются:

```bash
/language ui zh       # Китайский
/language ui en       # Английский
/language ui ru       # Русский
/language ui de       # Немецкий
/language ui ja       # Японский
```

### Авто-обнаружение

При первом запуске Nessy CLI обнаруживает вашу системную локаль и автоматически устанавливает язык UI.

Приоритет обнаружения:

1. Переменная окружения `NESSY_CLI_LANG`
2. Переменная окружения `LANG`
3. Системная локаль через JavaScript Intl API
4. По умолчанию: Английский

## Язык вывода LLM

Язык вывода LLM контролирует, на каком языке AI-ассистент отвечает, независимо от того, на каком языке вы вводите вопросы.

### Как это работает

Язык вывода LLM контролируется файлом правил в `~/.nessy/output-language.md`. Этот файл автоматически включается в контекст LLM во время запуска, инструктируя его отвечать на указанном языке.

### Авто-обнаружение

При первом запуске, если файл `output-language.md` не существует, Nessy CLI автоматически создаёт его на основе вашей системной локали. Например:

- Системная локаль `zh` создаёт правило для ответов на китайском
- Системная локаль `en` создаёт правило для ответов на английском
- Системная локаль `ru` создаёт правило для ответов на русском
- Системная локаль `de` создаёт правило для ответов на немецком
- Системная локаль `ja` создаёт правило для ответов на японском

### Ручная установка

Используйте `/language output \<language\>` для изменения:

```bash
/language output Chinese
/language output English
/language output Japanese
/language output German
```

Любое имя языка работает. LLM будет проинструктирован отвечать на этом языке.

:::note
После изменения языка вывода перезапустите Nessy CLI для вступления изменений в силу.
:::

### Расположение файла

```
~/.nessy/output-language.md
```

## Конфигурация

### Через диалог настроек

1. Запустите `/settings`
2. Найдите "Language" в разделе General
3. Выберите предпочитаемый язык UI

### Через переменную окружения

```bash
export NESSY_CLI_LANG=zh
```

Это влияет на авто-обнаружение при первом запуске (если вы не установили язык UI и файл `output-language.md` ещё не существует).

## Пользовательские языковые пакеты

Для переводов UI вы можете создавать пользовательские языковые пакеты в `~/.nessy/locales/`:

- Пример: `~/.nessy/locales/es.js` для испанского
- Пример: `~/.nessy/locales/fr.js` для французского

Пользовательская директория имеет приоритет над встроенными переводами.

### Формат языкового пакета

```javascript
// ~/.nessy/locales/es.js
export default {
  Hello: 'Hola',
  Settings: 'Configuracion',
  // ... больше переводов
};
```

## Связанные команды

- `/language` - Показать текущие настройки языка
- `/language ui [lang]` - Установить язык UI
- `/language output \<language\>` - Установить язык вывода LLM
- `/settings` - Открыть диалог настроек
