# Игнорирование файлов

Этот документ предоставляет обзор функции игнорирования Nessy (`.nessyignore`) Nessy CLI.

Nessy CLI включает возможность автоматически игнорировать файлы, аналогично `.gitignore` (используется Git). Добавление путей в ваш файл `.nessyignore` исключит их из инструментов, которые поддерживают эту функцию, хотя они всё ещё будут видны другим сервисам (таким как Git).

## Как это работает

Когда вы добавляете путь в ваш файл `.nessyignore`, инструменты, которые уважают этот файл, будут исключать соответствующие файлы и каталоги из их операций. Например, когда вы используете команду [`read_many_files`](../../../developers/work/tools/multi-file.md), любые пути в вашем файле `.nessyignore` будут автоматически исключены.

В основном `.nessyignore` следует соглашениям файлов `.gitignore`:

- Пустые строки и строки, начинающиеся с `#`, игнорируются.
- Поддерживаются стандартные glob-паттерны (такие как `*`, `?` и `[]`).
- Добавление `/` в конце будет соответствовать только каталогам.
- Добавление `/` в начале привязывает путь относительно файла `.nessyignore`.
- `!` инвертирует паттерн.

Вы можете обновить ваш файл `.nessyignore` в любое время. Для применения изменений вы должны перезапустить вашу сессию Nessy CLI.

## Как использовать `.nessyignore`

| Шаг                                | Описание                                                                                               |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Включить .nessyignore**          | Создать файл с именем `.nessyignore` в корневом каталоге вашего проекта                                |
| **Добавить правила игнорирования** | Открыть файл `.nessyignore` и добавить пути для игнорирования, например: `/archive/` или `apikeys.txt` |

### Примеры `.nessyignore`

Вы можете использовать `.nessyignore` для игнорирования каталогов и файлов:

```
# Исключить ваш каталог /packages/ и все подкаталоги
/packages/

# Исключить ваш файл apikeys.txt
apikeys.txt
```

Вы можете использовать подстановочные знаки в вашем файле `.nessyignore` с `*`:

```
# Исключить все .md файлы
*.md
```

Наконец, вы можете исключить файлы и каталоги из исключения с `!`:

```
# Исключить все .md файлы, кроме README.md
*.md
!README.md
```

Для удаления путей из вашего файла `.nessyignore` удалите соответствующие строки.
