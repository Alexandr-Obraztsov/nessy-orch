# Доверенные папки

Функция доверенных папок — это настройка безопасности, которая даёт вам контроль над тем, какие проекты могут использовать все возможности Nessy CLI. Она предотвращает запуск потенциально вредоносного кода, запрашивая у вас одобрение папки перед загрузкой любых специфичных для проекта конфигураций из неё.

## Включение функции

Функция доверенных папок **отключена по умолчанию**. Для её использования вы должны сначала включить её в ваших настройках.

Добавьте следующее в ваш пользовательский файл `settings.json`:

```json
{
  "security": {
    "folderTrust": {
      "enabled": true
    }
  }
}
```

## Как это работает: Диалог доверия

После включения функции, при первом запуске Nessy CLI из папки, автоматически появится диалог, предлагающий вам сделать выбор:

- **Доверять папке**: Предоставляет полное доверие текущей папке (например, `my-project`).
- **Доверять родительской папке**: Предоставляет доверие родительскому каталогу (например, `safe-projects`), что автоматически доверяет всем его подкаталогам. Это полезно, если вы держите все ваши безопасные проекты в одном месте.
- **Не доверять**: Помечает папку как недоверенную. CLI будет работать в ограниченном «безопасном режиме».

Ваш выбор сохраняется в центральном файле (`~/.nessy/trustedFolders.json`), поэтому вас спросят только один раз для каждой папки.

## Почему доверие важно: Влияние недоверенного рабочего пространства

Когда папка **недоверенна**, Nessy CLI работает в ограниченном «безопасном режиме» для вашей защиты. В этом режиме следующие функции отключены:

1.  **Настройки рабочего пространства игнорируются**: CLI **не** загружает файл `.nessy/settings.json` из проекта. Это предотвращает загрузку пользовательских инструментов и других потенциально опасных конфигураций.

2.  **Переменные окружения игнорируются**: CLI **не** загружает какие-либо `.env` файлы из проекта.

3.  **Управление расширениями ограничено**: Вы **не можете устанавливать, обновлять или удалять** расширения.

4.  **Автопринятие инструментов отключено**: Вам всегда будет предложено перед запуском любого инструмента, даже если у вас включено автопринятие глобально.

5.  **Автоматическая загрузка памяти отключена**: CLI не будет автоматически загружать файлы в контекст из каталогов, указанных в локальных настройках.

Предоставление доверия папке разблокирует полную функциональность Nessy CLI для этого рабочего пространства.

## Управление вашими настройками доверия

Если вам нужно изменить решение или просмотреть все ваши настройки, у вас есть несколько опций:

- **Изменить доверие текущей папки**: Выполните команду `/permissions` из CLI. Это вызовет тот же интерактивный диалог, позволяя вам изменить уровень доверия для текущей папки.

- **Просмотреть все правила доверия**: Чтобы увидеть полный список всех ваших правил доверенных и недоверенных папок, вы можете проверить содержимое файла `~/.nessy/trustedFolders.json` в вашем домашнем каталоге.

## Процесс проверки доверия (продвинутый)

Для продвинутых пользователей полезно знать точный порядок операций того, как определяется доверие:

**Локальный файл доверия**: CLI проверяет центральный файл `~/.nessy/trustedFolders.json`.
