# Инструмент списка задач (`todo_write`)

Этот документ описывает инструмент `todo_write` для Nessy CLI.

## Описание

Используйте `todo_write` для создания и управления структурированным списком задач для вашей текущей сессии кодирования. Этот инструмент помогает ИИ-ассистенту отслеживать прогресс и организовывать сложные задачи, предоставляя вам видимость того, какая работа выполняется.

### Аргументы

`todo_write` принимает один аргумент:

- `todos` (array, обязательно): Массив элементов todo, где каждый элемент содержит:
  - `content` (string, обязательно): Описание задачи.
  - `status` (string, обязательно): Текущий статус (`pending`, `in_progress` или `completed`).
  - `id` (string, обязательно): Уникальный идентификатор для элемента todo.

## Как использовать `todo_write` с Nessy CLI

ИИ-ассистент будет автоматически использовать этот инструмент при работе над сложными, многошаговыми задачами. Вам не нужно явно запрашивать это, но вы можете попросить ассистента создать список todo, если хотите увидеть планируемый подход к вашему запросу.

Инструмент хранит списки todo в вашем домашнем каталоге (`~/.nessy/todos/`) с файлами, специфичными для сессии, поэтому каждая сессия кодирования поддерживает свой собственный список задач.

## Когда ИИ использует этот инструмент

Ассистент использует `todo_write` для:

- Сложных задач, требующих нескольких шагов
- Реализаций функций с несколькими компонентами
- Операций рефакторинга через множество файлов
- Любых работ, включающих 3 или более различных действий

Ассистент не будет использовать этот инструмент для простых, одношаговых задач или чисто информационных запросов.

### Примеры `todo_write`

Создание плана реализации функции:

```
todo_write(todos=[
  {
    "id": "1",
    "content": "Создать модель пользовательских предпочтений",
    "status": "pending"
  },
  {
    "id": "2",
    "content": "Добавить API эндпоинты для предпочтений",
    "status": "pending"
  },
  {
    "id": "3",
    "content": "Реализовать фронтенд компоненты",
    "status": "pending"
  }
])
```

## Важные заметки

- **Автоматическое использование:** ИИ-ассистент управляет списками todo автоматически во время сложных задач.
- **Видимость прогресса:** Вы увидите обновляемые списки todo в реальном времени по мере выполнения работы.
- **Изоляция сессий:** Каждая сессия кодирования имеет свой собственный список todo, который не мешает другим.
