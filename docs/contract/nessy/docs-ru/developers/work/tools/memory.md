# Инструмент памяти (`save_memory`)

Этот документ описывает инструмент `save_memory` для Nessy CLI.

## Описание

Используйте `save_memory` для сохранения и вспоминания информации через ваши сессии Nessy CLI. С `save_memory` вы можете направить CLI запоминать ключевые детали через сессии, предоставляя персонализированную и направленную помощь.

### Аргументы

`save_memory` принимает один аргумент:

- `fact` (string, обязательно): Специфичный факт или часть информации для запоминания. Это должно быть ясное, самодостаточное утверждение, написанное на естественном языке.

## Как использовать `save_memory` с Nessy CLI

Инструмент добавляет предоставленный `fact` в ваш файл контекста в домашнем каталоге пользователя (`~/.nessy/NESSY.md` по умолчанию). Это имя файла может быть сконфигурировано через `contextFileName`.

После добавления факты хранятся в разделе `## Nessy Added Memories`. Этот файл загружается как контекст в последующих сессиях, позволяя CLI вспоминать сохранённую информацию.

Использование:

```
save_memory(fact="Your fact here.")
```

### Примеры `save_memory`

Запомнить предпочтение пользователя:

```
save_memory(fact="Мой предпочитаемый язык программирования — Python.")
```

Сохранить специфичную деталь проекта:

```
save_memory(fact="Проект, над которым я сейчас работаю, называется 'nessy-cli'.")
```

## Важные заметки

- **Общее использование:** Этот инструмент должен использоваться для кратких, важных фактов. Он не предназначен для хранения больших объёмов данных или истории разговора.
- **Файл памяти:** Файл памяти — это простой текстовый Markdown файл, поэтому вы можете просматривать и редактировать его вручную при необходимости.
