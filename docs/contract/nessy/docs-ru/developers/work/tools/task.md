# Инструмент задачи (`task`)

Этот документ описывает инструмент `task` для Nessy CLI.

## Описание

Используйте `task` для запуска специализированного субагента для выполнения сложных, многошаговых задач автономно. Инструмент Task делегирует работу специализированным агентам, которые могут работать независимо с доступом к своему собственному набору инструментов, позволяя параллельное выполнение задач и специализированную экспертизу.

### Аргументы

`task` принимает следующие аргументы:

- `description` (string, обязательно): Краткое (3-5 слов) описание задачи для видимости пользователем и отслеживания.
- `prompt` (string, обязательно): Детальная подсказка задачи для выполнения субагентом. Должна содержать комплексные инструкции для автономного выполнения.
- `subagent_type` (string, обязательно): Тип специализированного агента для использования для этой задачи. Должен соответствовать одному из доступных настроенных субагентов.

## Как использовать `task` с Nessy CLI

Инструмент Task динамически загружает доступные субагенты из вашей конфигурации и делегирует задачи им. Каждый субагент работает независимо и может использовать свой собственный набор инструментов, позволяя специализированную экспертизу и параллельное выполнение.

Когда вы используете инструмент Task, субагент будет:

1. Получать подсказку задачи с полной автономией
2. Выполнять задачу используя доступные инструменты
3. Возвращать финальное сообщение с результатом
4. Завершаться (субагенты без состояния и одноразовые)

Использование:

```
task(description="Краткое описание задачи", prompt="Детальные инструкции задачи для субагента", subagent_type="agent_name")
```

## Доступные субагенты

Доступные субагенты зависят от вашей конфигурации. Распространённые типы субагентов могут включать:

- **general-purpose**: Для сложных многошаговых задач, требующих различных инструментов
- **code-reviewer**: Для рецензирования и анализа качества кода
- **test-runner**: Для запуска тестов и анализа результатов
- **documentation-writer**: Для создания и обновления документации

Вы можете просмотреть доступные субагенты используя команду `/agents` в Nessy CLI.

## Возможности инструмента Task

### Обновления прогресса в реальном времени

Инструмент Task предоставляет живые обновления, показывающие:

- Статус выполнения субагента
- Индивидуальные вызовы инструментов, делаемые субагентом
- Результаты вызовов инструментов и любые ошибки
- Общий прогресс задачи и статус завершения

### Параллельное выполнение

Вы можете запустить несколько субагентов одновременно вызывая инструмент Task несколько раз в одном сообщении, позволяя параллельное выполнение задач и улучшенную эффективность.

### Специализированная экспертиза

Каждый субагент может быть сконфигурирован с:

- Специфичными разрешениями доступа к инструментам
- Специализированными системными подсказками и инструкциями
- Пользовательскими конфигурациями моделей
- Предметными знаниями и возможностями

## Примеры `task`

### Делегирование агенту общего назначения

```
task(
  description="Рефакторинг кода",
  prompt="Пожалуйста, рефакторьте модуль аутентификации в src/auth/ для использования современных паттернов async/await вместо callback. Убедитесь, что все тесты всё ещё проходят и обновите любую связанную документацию.",
  subagent_type="general-purpose"
)
```

### Запуск параллельных задач

```
# Запустить рецензирование кода и выполнение тестов параллельно
task(
  description="Рецензирование кода",
  prompt="Проверьте недавние изменения в модуле управления пользователями на качество кода, проблемы безопасности и соответствие лучшим практикам.",
  subagent_type="code-reviewer"
)

task(
  description="Запустить тесты",
  prompt="Выполните полный набор тестов и проанализируйте любые неудачи. Предоставьте сводку покрытия тестов и рекомендации для улучшения.",
  subagent_type="test-runner"
)
```

### Генерация документации

```
task(
  description="Обновить документацию",
  prompt="Сгенерируйте комплексную API документацию для недавно реализованных REST эндпоинтов в модуле заказов. Включите примеры запросов/ответов и коды ошибок.",
  subagent_type="documentation-writer"
)
```

## Когда использовать инструмент Task

Используйте инструмент Task когда:

1. **Сложные многошаговые задачи** - Задачи, требующие множества операций, которые могут быть выполнены автономно
2. **Специализированная экспертиза** - Задачи, которые выигрывают от предметных знаний или инструментов
3. **Параллельное выполнение** - Когда у вас есть несколько независимых задач, которые могут выполняться одновременно
4. **Потребности делегирования** - Когда вы хотите передать полную задачу, а не управлять шагами микроменеджментом
5. **Ресурсоёмкие операции** - Задачи, которые могут занять значительное время или вычислительные ресурсы

## Когда НЕ использовать инструмент Task

Не используйте инструмент Task для:

- **Простых, одношаговых операций** - Используйте прямые инструменты как Read, Edit и т.д.
- **Интерактивных задач** - Задачи, требующие общения туда-обратно
- **Специфичных чтений файлов** - Используйте инструмент Read напрямую для лучшей производительности
- **Простых поисков** - Используйте инструменты Grep или Glob напрямую

## Важные заметки

- **Выполнение без состояния**: Каждый вызов субагента независим без памяти предыдущих выполнений
- **Единое общение**: Субагенты предоставляют одно финальное сообщение с результатом — нет продолжающегося общения
- **Комплексные подсказки**: Ваша подсказка должна содержать весь необходимый контекст и инструкции для автономного выполнения
- **Доступ к инструментам**: Субагенты имеют доступ только к инструментам, настроенным в их специфичной конфигурации
- **Возможность параллелизма**: Несколько субагентов могут выполняться одновременно для улучшенной эффективности
- **Зависимость от конфигурации**: Доступные типы субагентов зависят от вашей системной конфигурации

## Конфигурация

Субагенты настроены через систему конфигурации агентов Nessy CLI. Используйте команду `/agents` для:

- Просмотра доступных субагентов
- Создания новых конфигураций субагентов
- Модификации существующих настроек субагентов
- Установки разрешений инструментов и возможностей

Для большей информации о конфигурировании субагентов смотрите документацию субагентов.
