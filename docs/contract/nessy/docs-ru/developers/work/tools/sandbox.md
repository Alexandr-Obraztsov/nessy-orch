# Настройка среды песочницы (Docker/Podman)

### В настоящее время проект не поддерживает использование функции BUILD_SANDBOX после установки через npm пакет

1. Для сборки пользовательской песочницы вам нужно получить доступ к скриптам сборки (scripts/build_sandbox.js) в репозитории исходного кода.
2. Эти скрипты сборки не включены в пакеты, выпущенные npm.
3. Код содержит жёстко закодированные проверки путей, которые явно отклоняют запросы сборки из сред, не являющихся исходным кодом.

Если вам нужны дополнительные инструменты внутри контейнера (например, `git`, `python`, `rg`), создайте пользовательский Dockerfile. Конкретная операция следующая:

#### 1. Сначала клонируйте проект Nessy CLI, https://gitlab.tcsbank.ru/nestor/nessy-cli.git

#### 2. Убедитесь, что вы выполняете следующую операцию в каталоге репозитория исходного кода

```bash
# 1. Сначала установите зависимости проекта
npm install

# 2. Соберите проект Nessy CLI
npm run build

# 3. Проверьте, что каталог dist был сгенерирован
ls -la packages/cli/dist/

# 4. Создайте глобальную ссылку в каталоге пакета CLI
cd packages/cli
npm link

# 5. Проверка ссылки (теперь она должна указывать на исходный код)
which nessy
# Ожидаемый вывод: /xxx/xxx/.nvm/versions/node/v24.11.1/bin/nessy
# Или похожие пути, но это должна быть символическая ссылка

# 6. Для деталей символической ссылки вы можете увидеть конкретный путь исходного кода
ls -la $(dirname $(which nessy))/../lib/node_modules/@nestor/nessy-cli
# Должно показать, что это символическая ссылка, указывающая на ваш каталог исходного кода

# 7. Протестируйте версию nessy
nessy -v
# npm link перезапишет глобальный nessy. Чтобы избежать невозможности различить одинаковый номер версии, вы можете сначала удалить глобальный CLI
```

#### 3. Создайте ваш sandbox Dockerfile в корневом каталоге вашего проекта

- Путь: `.nessy/sandbox.Dockerfile`

- Адрес официального образа: https://github.com/NessyLM/nessy/pkgs/container/nessy

```bash
# На основе официального образа песочницы Nessy (рекомендуется явно указать версию)
FROM ghcr.io/nessylm/nessy:sha-570ec43
# Добавьте ваши дополнительные инструменты здесь
RUN apt-get update && apt-get install -y \
    git \
    python3 \
    ripgrep
```

#### 4. Создайте первый образ песочницы в корневом каталоге вашего проекта

```bash
NESSY_SANDBOX=docker BUILD_SANDBOX=1 nessy -s
# Наблюдайте, согласуется ли версия инструмента песочницы, который вы запустили, с версией вашего пользовательского образа. Если согласуется, запуск будет успешным
```

Это собирает специфичный для проекта образ на основе образа песочницы по умолчанию.

#### Удаление npm link

- Если вы хотите восстановить официальный CLI nessy, пожалуйста, удалите npm link

```bash
# Метод 1: Отunlink глобально
npm unlink -g @nestor/nessy-cli

# Метод 2: Удалить в каталоге packages/cli
cd packages/cli
npm unlink

# Проверка поднята
which nessy
# Должно отобразить "nessy not found"

# Переустановите глобальную версию при необходимости
npm install -g @nestor/nessy-cli

# Проверка восстановления
which nessy
nessy --version
```
