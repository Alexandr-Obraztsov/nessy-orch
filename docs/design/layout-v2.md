# Раскладка v2: окно = терминал в папке, субагенты — в боковой панели

Итоговое решение пользователя (после нескольких итераций; образец стиля — Claude Desktop, вкладка Code). Дополняет `design-system.md`
и `screens.md`; при противоречии по раскладке и кнопкам приоритет у этого файла.

> **Окончательно:** слева — субагенты сессии (системный парящий сайдбар `NavigationSplitView`), в центре — терминал на всю высоту
> окна, шапки с названием нет (только светофор и системная кнопка панели). Прежние варианты (список сессий слева, панель агентов
> справа, вкладки терминалов, стартовый экран, группы проектов) отменены.

## Идея
Приложение — терминал, который открывается из любой папки и всегда оказывается ровно в ней. Один терминал на окно, терминал есть
всегда. Каждое окно = одна сессия оркестратора (один разговор Claude); слева видно, какие субагенты в ней работают.

```
┌─────────────────────┬──────────────────────────────────────────────┐
│ ●●●            ▤    │                                              │   ← светофор и кнопка панели лежат над панелью
│ Агенты · 3          │  $ claude                                    │
│ ┌─────────────────┐ │  ╭──────────────────────────╮                │
│ │ ◌ ci-fixer [роль]│ │  │ Claude Code …            │                │
│ │ ✓ ci-explorer   │ │  ╰──────────────────────────╯                │
│ └─────────────────┘ │                                              │
│ ● На связи  ◦ [👤][⋯]│                                              │
└─────────────────────┴──────────────────────────────────────────────┘
```

## Окна и запуск
- `WindowGroup(id: "terminal", for: TerminalWindowValue)` — значение `{key, dir, session?}`: одинаковые значения поднимают то же окно.
  `key` — случайный для нового окна и `s-<id сессии>` для повторного открытия сессии (из меню «Сессия», Dock, уведомления).
- Папка окна: `nessy-orch://terminal?dir=<путь>` (его делает `nessy-orch .` / `nessy-orch app [папка]`), файловый URL папки
  (`open -a "TClaude-Orch" .`, перетаскивание папки на значок: `CFBundleDocumentTypes` с `public.folder`), ⌘N (та же папка, что у окна
  в фокусе), ⇧⌘O «Открыть папку…». Запуск без папки (Dock, Spotlight) — окно в домашнем каталоге; его открывает невидимое окно
  `launcher` через 0,6 с, если за это время не пришла ссылка или папка.
- При открытии окна приложение создаёт сессию `POST /sessions {title: <имя папки>, owner: "claude"}` и кладёт в окружение терминала
  `NESSY_ORCH_SESSION`, `NESSY_ORCH_DIR`, `TERM=xterm-256color`, `COLORTERM=truecolor`, `LANG` (UTF-8), `ORCH_PORT` (если порт не 4337).
  Нет связи — терминал всё равно запускается, без сессии.
- Закрытие окна: терминал получает SIGHUP; живой процесс — только с подтверждением. Сессия без агентов и без состояния Claude
  удаляется (`DELETE /sessions/:id`), непустая остаётся. `exit` в оболочке закрывает окно. Выход из приложения с живыми терминалами —
  подтверждение.
- Меню «Сессия» и Dock: активные сессии оркестратора — открывают (поднимают) окно сессии; ⌘1…⌘9.

## Терминал и хуки Claude
- Оболочка — login-оболочка пользователя (`$SHELL`, запасная zsh) в папке окна. SwiftTerm `LocalProcessTerminalView`, SF Mono 13,
  отступ 12, приглушённая ANSI-палитра для обеих тем, акцентный курсор.
- Хуки подключены прозрачно для обычной команды `claude`: оболочка стартует с функцией `claude() { command claude --settings
  ~/.nessy-orch/claude-hooks.json "$@"; }` (если пользователь сам не передал `--settings`, а файл есть). Файлы пользователя не
  меняются: zsh читает точки входа из `~/.nessy-orch/zdotdir` (они подгружают настоящие `.zshenv`, `.zprofile`, `.zshrc`, а `.zshrc`
  возвращает `ZDOTDIR` пользователю), bash — `--rcfile ~/.nessy-orch/bashrc`, остальные оболочки — обёртка `~/.nessy-orch/bin/claude`
  в начале PATH. Скрипты и `claude-hooks.json` (SessionStart/UserPromptSubmit/Stop/SessionEnd → `nessy-orch hook start|prompt|stop|end`)
  пишет приложение перед стартом оболочки (`ShellIntegration`, `ClaudeHooks` в NessyKit, с тестами).
- Состояние Claude (`SessionView.claude.state`: working / idle / ended) — тихий индикатор внизу панели рядом с кнопками:
  лоадер — работает, синяя точка — ждёт вас, тусклая — завершил.

## Боковая панель (слева, системная)
- Ширина 300–440 (ideal 340), системный парящий сайдбар; кнопку скрытия и анимацию даёт система (в шапке слева, рядом со светофором);
  ⌘⌥B — то же с клавиатуры. Верхний отступ и раскладка в полноэкранном режиме — системные: отдельной логики для fullscreen нет.
- Содержимое — навигация список ⇄ карточка агента (пружина без отскока, Reduce Motion — кросс-фейд): список «Агенты · N» (строки:
  состояние, имя, чип роли, последняя команда) → клик → карточка (блок «Агент» + «План» + чат/итог + поле ввода). «×» — к списку.
- Низ панели: слева индикатор связи; справа тихая точка Claude и две круглые стеклянные кнопки — «Роли» и «⋯» (завершить / вернуть /
  удалить сессию, каталог в Finder, ссылка, Настройки…, Горячие клавиши).

## Центр
- Терминал на всю высоту окна. Пока панель открыта, шапка лежит над панелью и верхнего отступа у терминала нет; панель свёрнута —
  отступ равен высоте шапки (`window.contentLayoutRect`), сдвиг анимируется Core Animation, колонки и строки пересчитываются один раз.
  В полноэкранном режиме система рисует над контентом плоскую полосу тулбара, поэтому отступ там всегда включён.

## Кнопки (общее правило)
- Круглые, Liquid Glass, иконка без текста (подпись — `.help` и accessibilityLabel), справа в своей полосе, круг 36 pt, иконка 16,5 pt;
  не больше трёх в полосе; одна prominent на экран (здесь её нет — шапка без кнопок).
- Карта кнопок: панель, шапка карточки агента — «⋯», «×»; панель, низ — «Роли», «⋯»; карточка, поле ввода — «отправить»;
  чат — «к концу» (когда есть новое). В шапке окна только системная кнопка панели.

## Сделано / отклонения
- Сделано всё выше. Тесты: `swift test` (65), сборка `swift build` без предупреждений.
- Отклонение: переход список ⇄ карточка — собственный `ZStack` с пружиной, а не `NavigationStack` (на macOS у push нет управляемой анимации).
- Отклонение: в fullscreen система красит полосу тулбара непрозрачной; терминал под неё не заходит.
- Осиротевшие пустые сессии после аварийного завершения приложения (`kill`) не чистятся.
- Не проверено: bash и fish в роли login-оболочки (скрипты покрыты тестами, запуск — только zsh); ширина окна 1728 (экран 1470).

## Правки v2.1 (поверх всего выше; приоритет у них)
- Приложение называется **TClaude-Orch**. Окно без системной шапки (`hiddenTitleBar`): своя низкая шапка (высота по центру светофора, ≥34 pt)
  с кнопкой панели слева и «⋯» справа (только «Горячие клавиши» и «Настройки…»). Цвет окна, шапки и терминала один — шва и серой полосы нет.
- Терминал всегда начинается под шапкой: при открытии и закрытии панели меняется только его ширина. Светлой темы нет. Панель выезжает на всю высоту и накрывает светофор и кнопку панели; прокрутки «под шапку с размытием» нет:
  у терминала нет внутренней safe-зоны, поэтому применён запасной вариант — шапка всегда учитывается.
- Панель — стеклянная плитка (ширина 340, анимируется), внизу линия и кнопка «Роли» во всю ширину. Индикатора связи нет; состояние Claude — справа в заголовке списка.
- Полный экран: шапка прячется вместе с кнопками и выезжает у верхней кромки (материал с затемнением), терминал занимает всё место.
- Запуск без папки: системный выбор проекта по центру экрана (настройка «Спрашивать проект»). Finder: служба и быстрое действие «Открыть в TClaude-Orch».
- Один чат Claude = одна сессия оркестратора: хук `SessionStart` привязывает `session_id` чата (`POST /sessions/bind`, `SessionView.claudeId`),
  /resume возвращает ту же сессию, новый чат в окне получает новую (`origin` = первая сессия окна); `CLAUDE_ENV_FILE` отдаёт Bash-инструментам `NESSY_ORCH_SESSION`.

## Правка v2.2 (приоритет над v2.1 в части панели)
- Панель — снова системная (`NavigationSplitView`: парящее стекло, светофор и кнопка панели над ней, анимацию даёт система). Собственная плитка и шапка отменены.
- «⋯» — стеклянная кнопка тулбара справа (`ToolbarSpacer(.flexible)` + `ToolbarItem`): горячие клавиши и настройки.
- Высота терминала постоянна: отступ сверху = высота шапки (`contentLayoutRect`), панель меняет только ширину. В полноэкранном режиме шапка
  прячется вместе с меню (`.autoHideToolbar`), отступ 10 pt. Не проверено глазами: полный экран.
- «Горячие клавиши»: группы-списки на поверхности, без полос прокрутки, отскок только при необходимости.
- (v2.3) Панель открыта — терминал идёт с самого верха (отступ 8 pt) под прозрачной шапкой: поверх него только «⋯» и светофор над панелью.
  Панель закрыта — отступ плавно растёт до высоты шапки, чтобы светофор и кнопка панели не закрывали текст.
- (v2.4) Высота терминала при сворачивании и открытии панели меняется плавно (0,32 с, рамка пересчитывается каждый кадр от текущих границ).
  Полный экран: тулбар скрыт (шапка не растёт), системное окно-полоса `NSToolbarFullScreenWindow` прозрачно и не ловит мышь (серой полосы нет),
  кнопки панели и «⋯» — стеклянные круги в углах поверх терминала, всегда доступны.

## Правка v2.5 (окончательно для панели и шапки; отменяет v2.2–v2.4 в части раскладки)
- Окно `hiddenTitleBar`, системного тулбара нет (в полном экране нет серой полосы). Панель агентов — **своя**: колонка на всю высоту окна,
  чуть светлее терминала (`sidebarSurface`), справа тонкая линия; светофор и кнопка панели лежат на её верхней строке.
- Шапка — только кнопки: справа от светофора кнопка панели (иконка), справа стеклянная «⋯» (горячие клавиши, настройки). Высота = по центру светофора, ≥40.
- Терминал: панель открыта — отступ сверху 8, закрыта — высота шапки (плавно, 0,32 с); в полном экране то же самое.
- (v2.6) Палитра как у Claude Desktop: терминал, шапка и панель одного тёмного тона `#1C1C1E`, панель отделена тонкой линией; карточки `#262628`,
  выбор строки `#2A2E38`, текст `#F2F2F4`/`#A3A3AA`. Ширина панели 240–520 (по умолчанию 300): тянется за правый край (курсор ↔, линия
  подсвечивается акцентом), двойной щелчок — по умолчанию; значение общее для окон (`sidePanelWidth`).

## Правка v2.7 (окончательная раскладка)
- Терминал слева, не двигается; отступ сверху постоянный. Панель агентов справа — плитка Liquid Glass от верха окна (поле 8 pt) до низа.
- Общая линия шапки `barCenter` (26 pt): на ней светофор (система сдвигается приложением), заголовок «Агенты» и кнопки «панель» и «⋯». Кнопки лежат
  на стекле панели и ездят вместе с ней; когда панель скрыта, они собираются в свою стеклянную капсулу в том же месте.
- Внутри панели стеклянных кнопок нет: «⋯», «×», «отправить», «к концу» — простые иконки; стекло — только у панели и у шапки.
- Окна между запусками не восстанавливаются. Исправлено падение при старте (повторный вход в `CLISupport.shared`: поиск node теперь асинхронный).
