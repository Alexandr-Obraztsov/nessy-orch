# Окно «Фон»: замечания проверки на моках (21.10.2026)

Стенд: `npm run build && npm run demo:learning -- --fresh` (порт 4399), приложение: `open release/TClaude-Orch.app --args -serverURL http://127.0.0.1:4399 -debug.openBackground work`.

Проверено глазами: Работа, Кейсы (список, карточка, правка блоками, заметки, чат), Плейбуки (список, Ревью, Обзор), Настройки, Разбор прошлых, шапка (значок на «Роли»).
Не проверено: вкладки плейбука Кейсы/Правила/Заметки/История, правки «было → стало», журнал с записями, грязный кейс, длинный кейс, чат с сообщениями, чип и меню «⋯» в шапке сессии.

Дефекты:
1. JobCard (очередь): раскрытая карточка обрезана снизу — кнопки срезаны.
2. JobCard (идущее): пустой промежуток над первым сообщением живого чата.
3. Поповер якоря (`AnchorButton`): обрезан по высоте, строки наезжают; диапазон n 8–9 показывает одно событие.
4. Технические id в подписях: сессии `s-…` в строках списка кейсов и в чипе карточки, плейбук `p-…@N` в строке списка; чип плейбука в карточке — «Название@3» → «Название · v3».
5. Таблица действий кейса: при ширине окна 1000 сильно переносит; якорь `n 10–11` рвётся на две строки (нужен fixedSize); окно по умолчанию шире (≥1200).
6. Markdown в тексте кейса не рендерится: видны обратные кавычки.
7. План кейса: строки с лишним «- » в начале (и в просмотре, и в редакторе).
8. «Сборка плейбука» в очереди без подписи, какой задачи/группы она касается.
