# Справочник команд nessy-orch

Все команды поддерживают `--json`. `--timeout СЕК` задаёт ожидание для `--wait` и `ask` (по умолчанию 600 с).

**Всё, что ждёт (`--wait`, `ask`, `inbox --wait`), запускай только в фоне** — Bash с `run_in_background: true`.

**Работа идёт в задаче.** Первым делом `session new "<цель>" --owner claude` → id; дальше `spawn`, `ask`, `ls`,
`inbox` — с `--session <id>` (или переменная `NESSY_ORCH_SESSION=<id>`, явный флаг важнее). У каждой задачи свой inbox
с отдельным курсором: параллельные Claude не забирают ответы друг друга.

## Задачи

| Команда | Что делает |
|---|---|
| `session new "<заголовок>" [--owner X] [--id slug]` | Завести задачу: печатает id (первая строка) и ссылку `nessy-orch://session/<id>` |
| `session ls [--all]` | Задачи (по умолчанию активные): id, статус, владелец, число агентов |
| `session show <id>` | Задача и её агенты: статус, план `x/y`, последнее действие; итог, если есть |
| `session done <id> [--summary "…" \| --summary-file F]` | Закрыть задачу с итогом (в конце работы) |
| `session reopen <id>` | Снова сделать активной (пользователь вернулся к теме) |
| `session rm <id>` | Удалить задачу (агенты остаются вне задач); обычно вместо этого — `session done` |

## Агенты


| Команда | Что делает |
|---|---|
| `ask <путь\|пространство> "задача" [--session T]` | Создать агента и дождаться ответа (короткий путь) |
| `spawn --session T [--space S] [--name N] [--role R] [--wait] ["задача"]` | Создать агента в задаче; с `--wait` дождаться ответа. Агент, запущенный агентом, наследует задачу |
| `send <агент> "текст" [--wait] [--queue]` | Написать агенту (по имени или id); работающего прерывает, `--queue` — в очередь |
| `inbox --session T [--wait СЕК] [--peek]` | Новые ответы тебе от агентов задачи T (свой курсор на задачу); без `--session` — общий курсор по всем |
| `ls [--all] [--session T]` | Активные агенты (`--all` — и архивные): id, имя, роль, статус, пространство; `--session` — только задачи T |
| `show <агент> [-n 40]` | Последние события агента: что делал, какие инструменты, ошибки |
| `cancel <агент>` | Прервать текущий ход |
| `role ls` / `role show <id>` | Роли и их инструкции |
| `role import [путь] [--force] [--dry-run]` | Загрузить готовые роли из `roles/` (или из файла/папки markdown); `role export <id>` — обратно |
| `kill <агент>` | Удалить агента |
| `feed [-n 30]` | Общая лента всей переписки |
| `space ls` / `space add <путь> [--name N]` | Пространства (обычно создаются сами по пути) |
| `status` | Жив ли оркестратор |

## Ещё

| Команда | Что делает |
|---|---|
| `ask <путь\|пространство> "задача"` | Короткий путь: spawn --wait без роли |
| `archive <агент>` / `restore <агент>` | Убрать в архив / вернуть без сообщения |
| `role add <имя> --file F \| --instructions T [--description D] [--id ID]` | Завести роль (только если пользователь просит) |
| `role rm <id>` | Удалить роль |
| `watch <агент>` | Живой поток событий агента (для пользователя; тебе обычно хватает `show`) |

## Ошибки


| Симптом | Действие |
|---|---|
| «оркестратор недоступен» | Сам не запускай: ты в песочнице, и сервер с агентами оказались бы в ней же. Попроси пользователя выполнить в обычном терминале `bin/nessy-orch install` (сервис launchd) или `node ~/Projects/nessy-orch/dist/src/main.js`; если сервис уже установлен — `launchctl kickstart -k gui/$(id -u)/com.nessy.orch` |
| Код выхода 3 (таймаут) | Агент ещё работает: `plan <агент>`, затем снова фоновый `inbox --session <id> --wait 1500` |
| `[no_session]` | Задачи нет: `session ls --all`; нужна новая — `session new` |
| `[session_exists]` | Задача с таким `--id` уже есть — продолжай в ней или задай другой id |
| `[session_busy]` | `session rm` задачи с работающими агентами нельзя — дождись или `cancel`; обычно задачу закрывают `session done` |
| `[name_taken]` | Агент с таким именем уже есть — пиши ему через `send` или выбери другое имя |
| `[no_agent]` | Проверь имя или id через `ls` |
| Ответ с пометкой ошибки, статус `error` | `show <агент>`, чтобы увидеть причину; можно просто написать агенту снова (упавшая сессия пересоздастся, контекст сброшен) |
| Ответ «(ход прерван)» | Ход прервало новое сообщение или `cancel`; ответ на новое сообщение придёт отдельно |
| `[no_role]` | Проверь `role ls` |
| `[busy]` | `archive` работающего агента нельзя — дождись ответа или `cancel` |
| `[hop_limit]`, `[rate_limit]`, `[deadlock]` | Остановись, не повторяй в цикле, переформулируй задачу или сообщи пользователю |
| Код выхода 2 | Ошибка в аргументах команды: сверься с `nessy-orch --help` |
