# Рецепт: сводка задач Jira

Сначала загрузи скилл `nessy-orch` и иди по его циклу: шаг 0 (`session new "<цель>" --owner claude` → id, ссылка на панель задачи `nessy-orch://session/<id>`),
`ls --all --session <id>`, `role ls`. Все `spawn` — с `--session <id>`, сборщик — `inbox --session <id>`, в конце — `session done <id> --summary "…"`. Здесь — то, что специфично для отчёта по Jira.

## Когда

- Нужна сводка или таблица задач: по проекту, компоненту, эпику, спринту, исполнителю, периоду.
- Одна задача («какой статус у PAY-812») — тоже сюда, но поручение короче.

## Роли

| Шаг | Роль | Когда |
|---|---|---|
| Сбор и сводка | `jira-analyst` | всегда; по агенту на независимый срез (проект, команда) |
| Сверка | `verifier` | отчёт идёт наверх или от него зависит решение |

## Поручение

```bash
nessy-orch spawn --session <id> --space ~/tmp --role jira-analyst --name jira-<тема> "
Цель: <что собрать: открытые баги компонента payments> — для <зачем: планирование спринта / отчёт>.
Контекст: проект <KEY>, фильтр: <компонент, эпик, спринт, метки, исполнитель>, период <последние 30 дней>.
Границы: только чтение Jira, ничего не менять и не комментировать.
Результат: таблица ключ | заголовок | статус | исполнитель | приоритет | обновлено, отсортированная по <приоритету>;
под таблицей — итоги (сколько по статусам) и 3–5 наблюдений (зависшие, без исполнителя, блокеры).
Укажи использованный JQL.
Готово, когда: собраны все задачи по фильтру (или назван лимит и что не вошло).
В конце: строка «Статус: …»."
```

После `spawn` — фоновый `nessy-orch inbox --session <id> --wait 1500` (`run_in_background`).
Несколько срезов — несколько `spawn` без `--wait` (`jira-<проект1>`, `jira-<проект2>`), затем
фоновый `inbox --session <id> --wait 1500`, пока не придут все.

## Сводка пользователю

1. Итог одной-двумя фразами (сколько, что главное).
2. Таблица (если срезов несколько — общая или по разделу на срез, с указанием агента).
3. Наблюдения и риски: зависшие, без исполнителя, просроченные.
4. JQL, по которому собрано, — чтобы пользователь мог повторить.
5. Что не вошло или не проверено.

## Красные флаги

| Мысль | Как на самом деле |
|---|---|
| «Заодно пусть проставит метки / сменит статусы» | Только по прямой просьбе пользователя, отдельным поручением |
| «Таблица большая — перешлю как есть» | Сведи: итоги и наблюдения важнее сырого списка |
| «Цифры сходятся на глаз» | Сверь итоги с таблицей; спорное — `send` агенту или `verifier` |
| «Фильтр понятен без уточнений» | Неясно, что входит в выборку (период, статусы) — спроси пользователя до запуска |
