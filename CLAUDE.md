# nessy-orch — доступ к nessy из tclaude

Оркестратор поднимает `nessy serve` по воркспейсам и даёт тебе (tclaude) доступ
к полноценному nessy-агенту через простые CLI-команды. nessy умеет ходить в
dp-инструменты (GitLab, Jira, Sage, Wiki), править файлы, запускать shell,
запускать субагентов.

## Как пользоваться

Все команды идут в твоём Bash. Оркестратор живёт на `127.0.0.1:4337` (запускается
отдельно, вне песочницы).

### Отправить задачу nessy и дождаться ответа
```bash
nessy-ask <рабочая-папка> "текст задачи"
```
Живой лог (мысли, инструменты, текст) печатается в процессе; в конце — финальный
ответ. Exit 0 при успехе.

### Запустить задачу в фоне (чтобы вернуться к ней)
```bash
nessy-ask --bg <рабочая-папка> "текст задачи"
```
Печатает `job_id` сразу.

### Список активных nessy-задач
```bash
nessy-jobs
```

### Подписаться на живой лог задачи
```bash
nessy-watch <job_id>
```

## Когда это использовать
- Нужен агент, который ходит в dp (GitLab/Jira/Sage/Wiki) — у nessy они есть.
- Нужна длинная автономная работа (правка файлов, исследование, субагенты).
- Хочешь делегировать задачу второму агенту и наблюдать за ним.

Не используй nessy для субагентов — у тебя свои (Task). nessy-агент — для
отдельной параллельной работы или доступа к dp.

Если команда падает с «оркестратор недоступен» — скажи пользователю запустить
`node ~/Projects/nessy-orch/orchestrator.js`.
